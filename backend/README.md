# SentinelFS Cloud Backend (Layer 2 & Layer 5)

The **SentinelFS Backend** is a decoupled, asynchronous FastAPI application written in Python 3.11+. It orchestrates case management, investigator authentication, QR claim device pairing, evidence vault ingestion, Redis Stream job dispatching, FAISS cross-camera trajectory search, and BSA 63(4) statutory certificate packaging.

---

## 📑 Architecture & Modules

```
backend/
├── core/
│   ├── config.py              # Application settings (Pydantic BaseSettings)
│   └── security.py            # Password hashing (bcrypt) & JWT token decoding/encoding
├── database/
│   ├── connection.py          # Async SQLAlchemy engine (AsyncPG / aiosqlite) & session maker
│   └── models.py              # User, Case, Evidence, TimelineEvent, ClaimToken, AnalysisJob, AuditLog
├── routers/
│   ├── auth.py                # POST /api/v1/auth/register & login
│   ├── cases.py               # POST/GET /api/v1/cases, dispatch carving job
│   ├── claim.py               # QR claim registration, status polling (120 req/min), quick-redeem
│   ├── evidence.py            # Evidence vault intake (/ingest) & SHA-256/MD5 verification
│   ├── timeline.py            # Chronological events & cross-camera trajectory search
│   └── analysis.py            # Analysis job dispatch (/run), FAISS search, PDF report packaging
├── workers/
│   ├── celery_worker.py       # Celery task definitions (Rust carver launcher & progress telemetry)
│   ├── ml_worker.py           # Dedicated GPU Redis Stream consumer (sentinelfs:analysis:jobs)
│   └── result_consumer.py     # Redis Stream result consumer (sentinelfs:analysis:results)
├── dependencies.py            # Bearer token validation & scope dependencies
├── main.py                    # FastAPI entry point (REST & WebSockets)
└── tests/
    └── test_api.py            # Pytest test suite
```

## 📡 API Endpoint Reference

### Auth (`backend/routers/auth.py`)
- `POST /api/v1/auth/register`: Register new investigator (`username`, `email`, `password`, `badge_number`).
- `POST /api/v1/auth/login`: Authenticate and receive JWT access token.

### Cases (`backend/routers/cases.py`)
- `GET /api/v1/cases`: List all active cases.
- `POST /api/v1/cases`: Create a new forensic case.
- `GET /api/v1/cases/{case_id}`: Retrieve case details.
- `POST /api/v1/cases/{case_id}/carve`: Dispatch Rust carving job to Celery worker.

### Device Link Claim (`backend/routers/claim.py`)
- `POST /api/v1/claim/register`: Register claim token generated by edge agent.
- `GET /api/v1/claim/{token}/status`: Polling endpoint (rate-limited to 120 req/min per IP). Returns `pending` or `claimed` + case JWT.
- `POST /api/v1/claim/{token}/quick-redeem`: Web dashboard one-click device redemption.

### Evidence Vault (`backend/routers/evidence.py`)
- `POST /api/v1/evidence/ingest`: Recalculates dual SHA-256 and MD5 checksums on uploaded files/sub-clips, verifies against `manifest.json`, and inserts `Evidence` records.
- `POST /api/v1/evidence/{evidence_id}/verify-hash`: Re-verify file checksums on disk against database records.

### Analysis & Reporting (`backend/routers/analysis.py`)
- `POST /api/v1/analysis/run`: Enqueues ML analysis job onto Redis Stream `sentinelfs:analysis:jobs`.
- `POST /api/v1/analysis/search/cross-camera`: FAISS cross-camera trajectory correlation.
- `POST /api/v1/analysis/report/package`: Generates sealed case archive (`.case.zip`) containing PDF audit report, Section 63(4) BSA certificate, and Merkle root hash.

## ⚙️ Running & Testing Backend

```bash
# 1. Activate virtual environment
source .venv/bin/activate  # or .venv\Scripts\activate.ps1

# 2. Run backend dev server
uvicorn backend.main:app --reload --port 8000

# 3. Run Pytest suite
pytest backend/tests/test_api.py -v
```
