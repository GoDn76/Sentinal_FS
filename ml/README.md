# SentinelFS Machine Learning & Forensic Vision Subsystem (Layer 3)

The **SentinelFS ML Subsystem** provides GPU-accelerated video object tracking, suspect Re-ID, non-generative multi-frame face fusion, FAISS vector indexing with clock-drift correction, and legal report generation under **Section 63(4) of the Bharatiya Sakshya Adhiniyam (BSA), 2023**.

---

## 📑 Architecture & Pipelines

```
ml/
├── pipeline_a_person_tracker.py # YOLOv11 + ByteTrack + OSNet 512-dim L2 Re-ID + Vehicle HOG
├── face_fusion_v2.py            # MediaPipe + NAFNet + Burt-Adelson Laplacian blend + ArcFace
├── faiss_search.py              # FAISS IndexFlatIP cross-camera vector search & clock-drift sync
├── forensic_report.py           # Court package PDF report & ZIP archive sealer
├── train_denoiser_model.py      # NAFNet model architecture (NAFBlock, LayerNorm2d, PixelShuffle)
├── denoiser_inference.pth       # Trained NAFNet model weights
├── verify_setup.py              # PyTorch / CUDA environment check script
└── serve_api.py                 # ML Service API entry point
```

## 🔍 Detailed Pipeline Specifications

### Pipeline A — Person & Vehicle Analysis (`pipeline_a_person_tracker.py`)
1. **Object Detection**: YOLOv11 (`yolo11m.pt`) detects persons (class 0), vehicles (cars, motorcycles, buses, trucks), and carried objects.
2. **Multi-Object Tracking**: ByteTrack persistent tracking (`bytetrack.yaml`) maintains track IDs across frames.
3. **Person Re-ID**: OSNet (`osnet_x1_0`) embeds 256x128 person crops into **512-dimensional L2-normalized vectors** for cross-camera search.
4. **Vehicle Descriptor**: Computes HSV color histograms (192 bins) + HOG shape descriptors.

---

### Pipeline B — Non-Generative Multi-Frame Face Fusion (`face_fusion_v2.py`)
1. **Face Landmarking & Alignment**: MediaPipe 468-point 3D FaceMesh landmarker; 5-point affine transformation to 256x256 template.
2. **Relative Quality Scoring**: Evaluates 8 semantic facial regions (forehead, eyes, nose, mouth, chin, cheeks) measuring Laplacian variance sharpness, contrast, exposure, clipping, and landmark RMS geometry deviation against `sharp_ref`.
3. **NAFNet Non-Generative Denoising**: Passes crops through NAFNet (`NAFBlock` with `SimpleGate`, `LayerNorm2d`, `PixelShuffle` upsampling decoder) to remove sensor noise without hallucination ($y = x + \text{net}(x)$).
4. **Burt-Adelson Multiband Blending**: Fuses regional crops using a 5-level Laplacian pyramid (`multiband_blend`), producing `composite.png` and `attribution_overlay.png`.
5. **ArcFace Embedding**: InsightFace ArcFace (`w600k_r50`) extracts a **512-dimensional L2-normalized vector** from `composite.png` for FAISS vector search.

---

### FAISS Vector Search & Clock-Drift Correction (`faiss_search.py`)
- Uses FAISS `IndexFlatIP` (Inner Product / Cosine Similarity) for fast 512-dimensional vector search.
- Corrects out-of-phase DVR clock offsets per camera channel during index insertion:
  $$t_{\text{corrected}} = t_{\text{raw}} + \Delta t_i$$

---

### GPU Redis Stream Worker (`backend/workers/ml_worker.py`)
- Dedicated worker process listening to Redis Stream `sentinelfs:analysis:jobs`.
- Reads job payloads, runs Pipeline A & B, indexes vectors into FAISS, publishes results to `sentinelfs:analysis:results`, and calls `xack`.

## ⚖️ Section 63(4) BSA 2023 Compliance

Every output image and PDF report generated by this subsystem includes:
- NAFNet model checkpoint SHA-256 hash.
- Per-region source frame attribution log (`attribution.json`).
- Non-generative processing proof statement guaranteeing zero AI hallucination.
